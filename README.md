# Shopware (shopware)

Shopware is an open-source, API-first e-commerce platform built on Symfony and Vue.js, serving mid-market and enterprise merchants across B2C, D2C, and B2B use cases. The platform exposes two primary HTTP APIs — an Admin API (OAuth 2.0) for back-office integrations and a Store API for headless storefronts — each publishing machine-readable OpenAPI 3 specifications. Shopware is available as a free Community Edition (MIT) and as paid SaaS/self-hosted tiers (Rise, Evolve, Beyond).
